# Flux de treball de pull requests

1. Confirma el repositori, la branca base i la branca actual. Revisa el diff
   complet i comprova que només inclou la feina acordada.
2. Llegeix l'`AGENTS.md`, la plantilla de pull request, els workflows de CI i
   les regles vigents del repositori. Aquestes fonts —no una skill genèrica—
   defineixen les comprovacions, etiquetes, persones revisores, format del títol
   i seccions obligatòries.
3. Executa les comprovacions aplicables i anota'n els resultats reals. No
   marquis com a superada cap comprovació no executada.
4. Publica només la branca prevista. Crea la pull request amb les eines
   documentades pel repositori i omple totes les seccions requerides.
5. Verifica la branca base, el títol, la descripció, les etiquetes i les
   comprovacions de la pull request. Si alguna política és ambigua, pregunta
   abans de crear-la.

No assumeixis que tots els repositoris comparteixen una plantilla o política
de pull request.
